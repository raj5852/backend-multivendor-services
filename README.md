# Multi-Vendor E-commerce (Only API)

A powerful Laravel-based API for a multi-vendor e-commerce platform, offering subscription plans, affiliate services, and payment integration.

## Features

1. **Multi-Merchant Support**
   - Merchant can sell products and manage their stores.

2. **Affiliate System**
   - Drop Shipper can promote merchant products.
   - Drop Shipper can also create and sell services.

3. **Service Purchases**
   - Users can browse and buy services offered by merchant or drop shipper.

4. **Subscription Plans**
   - Three subscription options: Free, Monthly, and Yearly.
   - Subscription expiration alerts for users.

5. **Subscription Renewal**
   - Users can renew their subscriptions using:
     - Aamarpay Payment Gateway
     - My Wallet balance

6. **Wallet Recharge**
   - Users can recharge their wallet via the Aamarpay payment gateway.
